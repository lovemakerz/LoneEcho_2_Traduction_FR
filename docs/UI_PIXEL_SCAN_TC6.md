# UI PIXEL SCAN — TC6

Référence visuelle exacte : `assets/interface_reference_originale_1200x651.png`
Dimensions natives : **1200 × 651 px**.

Zones interactives détectées directement sur les contours du PNG :

- Fermer : x=1123..1161, y=30..66
- Parcourir : x=1028..1141, y=460..486
- Installer la traduction : x=37..593, y=522..596
- Désinstaller la traduction : x=610..1161, y=523..595
- À propos : x=42..139, y=605..643

Règle TC6 : aucun cadre de survol n'est dessiné par le programme. Les cadres visibles sont exclusivement ceux du PNG de référence. Les boutons Fermer et À propos ne reçoivent donc aucun cadre graphique additionnel.

Les seuls éléments repeints dynamiquement sont le contenu interne du champ de chemin et, si nécessaire, les textes d'état/version. Les bordures existantes du PNG ne sont pas redessinées.
